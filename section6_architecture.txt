Розділ 6. Архітектура системи та залежності між підсистемами
6.1 Загальна архітектура системи

Інформаційна система онлайн-магазину електроніки будується за трирівневою (Three-Tier) архітектурою:

Рівень представлення (Frontend)

Рівень бізнес-логіки (Backend)

Рівень даних (Database)

6.2 Опис рівнів архітектури
1. Рівень представлення (Frontend)

Відповідає за взаємодію користувача із системою.

Функції:

Відображення каталогу товарів

Реєстрація та авторизація

Робота з кошиком

Оформлення замовлення

Адміністративна панель

Користувачі:

Гість

Зареєстрований користувач

Адміністратор

2. Рівень бізнес-логіки (Backend)

Відповідає за обробку запитів та реалізацію логіки системи.

Основні модулі:

Модуль управління користувачами

Модуль управління товарами

Модуль кошика

Модуль замовлень

Модуль адміністрування

3. Рівень даних (Database)

Відповідає за зберігання інформації:

Дані користувачів

Дані товарів

Дані замовлень

Дані кошика

6.3 Залежності між підсистемами

Frontend → надсилає HTTP-запити → Backend
Backend → обробляє логіку → звертається до Database
Database → повертає дані → Backend → Frontend

Залежності:

Frontend залежить від API Backend

Backend залежить від структури бази даних

Модуль замовлень залежить від модуля кошика

Модуль адміністрування залежить від модуля товарів та користувачів

6.4 Тип архітектури

Система є клієнт-серверною веб-архітектурою з централізованою базою даних.
